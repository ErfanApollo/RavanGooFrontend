
# روان‌گو 🧠🌿

**روان‌گو** یک وب‌سایت تخصصی در حوزه روان‌شناسی است که با هدف افزایش آگاهی عمومی، خودشناسی و بهبود سلامت روان طراحی شده است. این وب‌سایت شامل تست‌های روان‌شناسی معتبر، مقالات علمی و وبلاگ‌های متنوع در زمینه‌های مختلف روان‌شناسی می‌باشد.

## 🛠️ تکنولوژی‌های استفاده‌شده

- Frontend: HTML, CSS, JavaScript
- Backend: Django
